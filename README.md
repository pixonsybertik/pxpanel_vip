# PX Panel PRO

نسخه تجاری سبک برای تیم‌های فروش کانفیگ · بهینه Railway

## ورود
| مسیر | کار |
|------|-----|
| `/setup` | تنظیم رمز (فقط یک‌بار) |
| `/pxpanelworking` | ورود امن مدیریت |
| `/dashboard` | پنل |

بدون `/login` عمومی.

## پروتکل‌ها
- **VLESS WS** — پایدار روی Railway
- **XHTTP Fast** — در تنظیمات پیشرفته

## ویژگی
- تم مات مینیمال · سایدبار چپ · فقط SVG
- پوشه‌ها · محدودیت IP/کاربر/سرعت
- ساب حرفه‌ای · آمار منابع
- بدون صفحه پشتیبانی/حمایت

## دیپلوی Railway
Volume → `/data` · Generate Domain · `bash start.sh`
